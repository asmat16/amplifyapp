# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

**Spidoo Rey** — a 30–35 second vertical (1080×1920, 9:16) Remotion reel about a giant Spider-Man parody character in a Pakistani village. Four cinematic scenes with Urdu voiceover generated via ElevenLabs.

## Commands

```bash
npm install                          # install all dependencies
npm start                            # open Remotion Studio (hot-reload preview)
npm run render                       # render final MP4 to out/spidoo-rey.mp4

# Generate Urdu voiceover via ElevenLabs (requires API key)
ELEVENLABS_API_KEY=<key> npm run voiceover   # uses npx tsx internally
```

Run a single Remotion render pass for a specific frame range:
```bash
npx remotion render SpidooRey out/preview.mp4 --frames=0-90
```

## Architecture

```
src/
  Root.tsx                — registers the <SpidooRey> Composition
  voiceover-config.ts     — scene data: Urdu text, default durations, image prompts
  get-audio-duration.ts   — mediabunny helper used by calculateMetadata
  SpidooReyVideo.tsx      — main composition + calculateMetadata
  scenes/Scene{1-4}.tsx   — individual scene components
  components/
    KenBurns.tsx           — Ken Burns pan/zoom effect; accepts null src → placeholder colour
    CinematicOverlay.tsx   — vignette, letterbox bars, mood tint, fade-in/out
    Subtitle.tsx           — RTL Urdu text + wires up <Audio> for the scene's voiceover
generate-voiceover.ts     — standalone Node script; calls ElevenLabs for each scene
public/
  images/scene{1-4}.jpg  — AI-generated scene images (see imagePrompt in voiceover-config.ts)
  voiceover/scene{1-4}.mp3 — generated by `npm run voiceover`; gitignored
```

### Data flow

1. `calculateMetadata` (in `SpidooReyVideo.tsx`) runs before rendering. It tries to read each `public/voiceover/scene{N}.mp3` duration via mediabunny. Missing files fall back to `defaultDurationInSeconds` in `voiceover-config.ts`. It returns `sceneDurationsInFrames` and `audioAvailable` as props.
2. The composition uses `<TransitionSeries>` with 20-frame `fade` crossfades between the four scenes.
3. Each `Scene{N}` renders `<KenBurns>` → `<CinematicOverlay>` → `<Subtitle>` (which also mounts `<Audio>` when `audioAvailable` is true).

### Adding scene images

Each scene in `voiceover-config.ts` has an `imagePrompt` field — paste it into Midjourney, DALL-E 3, or Stable Diffusion (1080×1920 or any 9:16 output), then save as:

```
public/images/scene1.jpg   # Chai shop — warm amber
public/images/scene2.jpg   # Rainy walk — blue-grey
public/images/scene3.jpg   # Rescue action — dramatic
public/images/scene4.jpg   # Aftermath — golden hour
```

The `KenBurns` component shows a dark placeholder colour until the image file exists.

### Changing voice / language

Edit `VOICE_ID` in `generate-voiceover.ts` (or set `ELEVENLABS_VOICE_ID` env var). Browse voices at `elevenlabs.io/voice-library`. The script uses `eleven_multilingual_v2` which supports Urdu natively.

To change the Urdu script, edit the `urduText` fields in `src/voiceover-config.ts`, then re-run `npm run voiceover`.

## Key conventions

- All remotion packages must stay on the same major version (currently `^4.0.0`).
- Scene timing is audio-driven: edit `defaultDurationInSeconds` in `voiceover-config.ts` only as the fallback when no MP3 is present.
- `useCurrentFrame()` inside a `<Sequence>` or `<TransitionSeries.Sequence>` returns a **local** frame starting at 0, not the composition-level frame.
- Keep `TRANSITION_DURATION_FRAMES` consistent — `calculateMetadata` subtracts it from the total duration; the `<TransitionSeries.Transition>` uses the same value.
